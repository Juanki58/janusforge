## 16. Research governance rules

### Taxonomía de estados documentales

| Etiqueta | Definición |
|----------|------------|
| **CURRENT** | Decisión operativa vigente |
| **SUPERSEDED** | Estado operativo anterior reemplazado explícitamente por decisión posterior |
| **CONFLICT** | Dos declaraciones operativas incompatibles sin cierre posterior |
| **UNRESOLVED** | No necesariamente conflicto; relación/autoridad entre ámbitos aún no cerrada |
| **HISTORICAL** | Etapa anterior para trazabilidad, sin instrucción operativa actual |

**HISTORICAL ≠ automáticamente SUPERSEDED.** Un estado puede ser HISTORICAL (trazabilidad) sin haber sido etiquetado SUPERSEDED por un patch explícito de supersesión.

4. **Conflictos no se resuelven por inferencia** — marcar CONFLICT / UNRESOLVED hasta patch explícito.
