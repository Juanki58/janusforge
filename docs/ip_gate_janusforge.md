## Disclaimer (mandatory)

This file is an **internal R&D sequencing rule**. It is **not** legal advice, **not** an FTO opinion, and **not** a patentability opinion. **Blue-ocean / white-space ideas are exploratory hypotheses for counsel review — not clearance to operate or invent.** A registered patent attorney/agent must review patentability and FTO before any claim that a Janusforge molecule is patentable, free to operate, or ready for public disclosure.

## Confidentiality policy

- No **public** proprietary NCE SMILES, InChI, or structure images.  
- No **public** GitHub of proprietary structure libraries (gitignore / private).  
- **Published** Qiu / URB447 / GW405833 / AM1710 may be discussed.  
- **NDA** before sharing unpublished structures with third parties.  
- Prefer compound IDs over structures in public tickets/PRs.  
- Scrub public repos before preprint / conference / fundraising decks.
